## English

WYSIWYG text editor for Moodle (`editor_tiptap`) built on [@kelsoncm/tiptap-core](https://kelsoncm.github.io/tiptap-core/) (Tiptap 3). The administrator chooses the toolbar (preset or custom), the mode and the features, and manages extra features installed as TipTap plugins (subplugins `tiptap_*`): images and media from the Moodle file picker, links to activities and mathematical notation for the Moodle filters come bundled. Saves plain HTML. Supports Moodle 4.5 LTS and 5.3 LTS.

Install: upload the release ZIP at *Site administration > Plugins > Install plugins*, or clone this repository to `public/lib/editor/tiptap` (`lib/editor/tiptap` on Moodle 4.5) and visit *Site administration > Notifications*. Then enable it at *Site administration > Plugins > Text editors > Manage editors*.

## Português (Brasil)

Editor de texto WYSIWYG para o Moodle (`editor_tiptap`) construído sobre o [@kelsoncm/tiptap-core](https://kelsoncm.github.io/tiptap-core/) (Tiptap 3). O administrador escolhe a barra (modelo ou personalizada), o modo e os recursos, e gerencia recursos extras instalados como plugins do TipTap (subplugins `tiptap_*`): imagens e mídia pelo seletor de arquivos do Moodle, links para atividades e notação matemática para os filtros do Moodle vêm incluídos. Salva HTML simples. Compatível com o Moodle 4.5 LTS e 5.3 LTS.

Instalação: envie o ZIP da release em *Administração do site > Plugins > Instalar plugins*, ou clone este repositório em `public/lib/editor/tiptap` (`lib/editor/tiptap` no Moodle 4.5) e acesse *Administração do site > Notificações*. Depois habilite-o em *Administração do site > Plugins > Editores de texto > Gerenciar editores*.
